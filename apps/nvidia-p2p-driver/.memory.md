## nvidia-p2p-driver

Build-environment-container app (corefreq pattern): compiles the aikitoria
GeForce-P2P-patched NVIDIA open kernel modules inside a container against the running
host kernel, then installs the `.ko`s onto the host to enable PCIe P2P on consumer
GPUs. Replaces the old loose `~/rebuild-nvidia-p2p.sh` + pacman-hook approach with a
versioned app + manual rebuild. See [[nvidia-p2p-patch-kernel-update-orphaning]].

## Implementation

- **Multi-base** `Dockerfile.arch` (Clang/LLVM — this host) + `Dockerfile.ubuntu`
  (GCC), auto-picked by `host_distro_family` in `cmd_build` (`lib/commands.sh`). The
  Arch variant is mandatory on CachyOS: Clang+ThinLTO kernels need the LLVM toolchain
  (`clang lld llvm`), plus `pahole` for BTF. Same rationale as corefreq.
- **`create_flags`** = `--privileged -v /usr/src:/usr/src:ro -v /lib/modules:/lib/modules:ro`
  — build against the host kernel. `/lib/modules` is **read-only**, so the container
  can build but NOT install; the copy-to-`updates/` + `depmod` + initramfs regen runs
  on the host.
- **Two baked scripts** (COPY'd in, not `printf`'d like corefreq):
  - `nvidia-p2p-build` (`bin:` export, runs in container): driver-version guard →
    Clang autodetect (`CONFIG_CC_IS_CLANG=y` → `LLVM=1 CC=clang LD=ld.lld …`) →
    objtool host-lib staging from `/run/host` → `make -C $SRC modules SYSSRC=$KBUILD`
    → stage `kernel-open/*.ko` to `~/.local/nvidia-p2p/` → `distrobox-host-exec sudo
    nvidia-p2p-install-ko`.
  - `nvidia-p2p-install-ko` (`/usr/share/nvidia-p2p/`, runs on host as root): copy
    `.ko` → `/lib/modules/<kver>/updates/`, `depmod`, regenerate initramfs
    (`mkinitcpio -P` / `dracut -f --regenerate-all` / `update-initramfs -u -k all`).
- **Fork pin** via `ARG P2P_REMOTE`/`P2P_BRANCH` (default aikitoria `610.43.03-p2p`),
  cloned at image build. `ARG CACHE_BUST` (set by `tools build`) re-pulls the branch.
- **Durability = manual** (chosen with user): no pacman hook, no host toolchain. Re-run
  `nvidia-p2p-build` after a kernel/nvidia-open upgrade, then reboot.

## Pitfalls and notes

- **The module can't be hot-swapped** (unlike corefreq's `insmod`) — nvidia is in use
  by the display. Install to `updates/` + `mkinitcpio -P`, then **reboot**. Two things
  must both happen or stock loads at early boot: build for the new kernel AND
  regenerate the initramfs (the `kms` hook bakes nvidia in). Verify with
  `cat /sys/module/nvidia/srcversion` = the patched build.
- **`updates/` outranks `extramodules/`/`kernel/`** in depmod search order, so the
  patched module wins over the stock nvidia-open package. Uncompressed `.ko` in
  `updates/` loads fine even though host modules are `.ko.zst` (kmod handles both).
- **Driver-version guard** reads the host's loaded version from
  `distrobox-host-exec cat /sys/module/nvidia/version` (cross-distro, no pacman). If
  the fork pin ≠ host driver, it refuses (a mismatched module won't load and would
  break the GPU). Best-effort: skipped if the host read fails.
- **objtool host-lib staging** (corefreq pitfall): kernel-headers ship a prebuilt
  `tools/objtool/objtool` linked against the HOST's binutils; on a rolling host it can
  need a newer shared lib than the container has, and `/usr/src` is read-only so it
  can't be rebuilt. Fix: `ldd` it, copy each `not found` lib from `/run/host/usr/lib`
  into a scratch dir, point `LD_LIBRARY_PATH` at just that dir (never the whole host
  lib tree — it shadows the container's glibc/libstdc++).
- **This app has a Dockerfile, so it is NOT the container-less host-only kind** — it
  builds a real box (`is_hostonly_installer` returns false). Its two sibling apps
  (`nvidia-cdi-service`, `nvidia-acs-service`) are the container-less ones.
- **`nvidia-smi`/CUDA are NOT in this image** — it's a pure build box (no CDI in
  `create_flags`), so the version guard uses `/sys/module/nvidia/version` via
  host-exec rather than `nvidia-smi`.
- P2P also needs `nvidia-acs-service` (clear ACS redirect) + `iommu=pt`; without ACS
  cleared the switch bounces peer TLPs to the root complex (~1 GB/s + corruption).
- The old `~/rebuild-nvidia-p2p.sh` + `zz-nvidia-p2p-rebuild.hook` (host pacman-hook
  auto-rebuild) are **superseded** by this app and were dropped.
