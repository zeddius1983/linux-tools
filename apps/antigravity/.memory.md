## antigravity

Google's AI CLI tool (similar to Claude Code and Codex CLI). Installed from the official Google installer at `antigravity.google`. Exported to the host as `agy`.

## Implementation

**Base image**: `docker.io/ubuntu:24.04`

**Install**: Official installer script pulled from `antigravity.google/cli/install.sh`, placed at `/usr/bin`.

**Dependencies**: `curl`, `ca-certificates`, `git`, `jq`, `gh` (GitHub CLI — installed from the official GitHub APT repo).

**Export**: `bin:agy` + `desktop:agy:Antigravity CLI`

## Pitfalls and notes

- The installer is fetched at image-build time — rebuild the image to pick up new releases.
- **Marked unmaintained** (`unmaintained` marker file): it still installs, but it isn't being kept current. The dashboard greys it out and sorts it last in the Development tab, and `tools list` flags it. The `README.md` was added in the same change.
- **`FROM` is fully qualified** (`docker.io/ubuntu:24.04`, Oct 2026): it was grandfathered in `LEGACY_UNQUALIFIED_FROM`, which is now empty. Same image, but it no longer depends on the host having an unqualified-search registry configured.
- **distrobox-init's first-start packages are preinstalled** (2026-10-27) through the shared
  `lib/distrobox-deps` step near the top of the Dockerfile, so a fresh box's
  `Installing basic packages...` is a no-op instead of a ~250-package download (see
  "Distrobox first-start packages" in `AGENTS.md`). It builds only through `tools`, which
  passes the `distrobox-deps` build context; a bare `podman build` fails at that `COPY`.
