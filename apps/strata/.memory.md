## strata

[Strata](https://github.com/Niko1221/Strata): a local LLM server built only for
Qwen3.8-Flash-Next (125B MoE) and its variants, plus Qwen3.6-35B-A3B. It keeps the
busiest experts on the GPU and the rest in RAM. It is not a general GGUF runner;
other architectures belong in llama-cpp / lmstudio / vllm. Packaged because it is
the practical way to run that model on the dev host (Strix Halo, gfx1151, 128 GB).

## Implementation

- **What is packaged:** the *Terminal* (`strata` CLI, which also serves the web chat
  page), not the Tauri AppImage. The AppImage would add WebKit/Tauri deps, FUSE
  workarounds and a different file per GPU for no functional gain. Building from
  source (TheRock ROCm 7.14.1, ~25 min) is also skipped: upstream ships a signed
  `hip-halo` engine for gfx1151.
- **Base:** `docker.io/ubuntu:24.04`, the same base as upstream's `docker/Dockerfile`.
  The apt list is upstream's runtime set (common + `FLAVOR=hip`: `libdrm-amdgpu1
  libelf1t64 libtinfo6 libpci3` ...) plus `curl git pciutils procps`. No ROCm in the
  image: every engine package carries its own ROCm/CUDA runtime.
- **Install step:** upstream's own `install.sh`, run at build time with
  `STRATA_FEED=<release folder>`, `STRATA_DATA_DIR=/opt/strata` and
  `STRATA_BIN_DIR=/opt/strata/bin`. It checks the SHA-256 against
  `install-manifest.txt` and verifies the release's signed feed. A tag pins the feed to
  `releases/download/<tag>`, and `latest` uses `releases/latest/download`. The Terminal
  lands at `/opt/strata/terminal/<version>`, with a `current` symlink.
- **Engine and Control are NOT in the image.** They go to
  `~/.local/share/strata/components` (the default `STRATA_COMPONENTS_DIR`), i.e. shared
  `$HOME`. The first `strata launch` or `strata update` fetches the one matching
  `/sys/class/kfd` topology (gfx1151 → `hip-halo`). This keeps rebuilds cheap, keeps
  one image for AMD and NVIDIA, and lets `strata update`'s test-start/rollback work as
  upstream designed.
- **Wrappers in /usr/bin:** `strata` execs the Terminal launcher. `strata-launch` runs
  `strata launch` and then waits for Enter, so the desktop entry's terminal window
  doesn't vanish with the printed addresses. Exports: `bin:strata`,
  `desktop:strata-launch:Strata`. The icon is upstream's Tauri `icon.png` (512px).
- **Wizard:** `00-gpu.runtime` (`STRATA_GPU`, amd/nvidia) only selects
  `create_flags` / `create_flags.nvidia` (CDI, as in lmstudio). `01-release.buildarg`
  (`STRATA_REF`) is an `items-cmd` over the GitHub *releases* API, filtered to v0.2+,
  with `latest` first.
- **Verified on the dev host (Mint 22.3, Strix Halo, Oct 2026):** build at `latest`
  (0.2.3.1) and pinned `v0.2.2`. `strata launch --plan --model q2_0` picked Q2_0
  128K, about 72.5 GB to download. `strata update` installed `0.1.48
  linux-x86_64-hip-halo`. HIP from the engine's own `libamdhip64` inside the box saw
  "AMD Radeon 8060S Graphics" with 121/124 GiB free. **Not yet run: a real model
  download + serve.**

## Pitfalls and notes

- **Release tags ≠ releases.** The repo has tags like `v0.2.1.4` with no GitHub
  release, and v0.1.x releases have no `install.sh` / `install-manifest.txt` (the
  Terminal arrived in v0.2.0-beta). So the picker lists *releases* from the API, not
  `git ls-remote` tags, and drops v0.1.x. A tag without a release 404s on `install.sh`.
- **`STRATA_DATA_DIR` / `STRATA_BIN_DIR` are install.sh-only.** Don't set them as image
  `ENV`. At runtime, `STRATA_DATA_DIR` makes the Terminal look for an `install/` folder
  under it (`discovery.places`), which would point it at root-owned `/opt/strata`.
- **The upstream installer's `strata update --check` runs at build time** as root with
  `HOME=/root`. Its leftovers in `/root/.local/share/strata` etc. are removed in the same
  layer.
- **No `--ulimit memlock` in create_flags**, for the same reason as fastflowlm: rootless
  Podman can't exceed the host user's hard limit (64 GiB on the dev host), and asking
  for more fails container start. Strata warns and runs. The README documents the host
  `limits.d` fix.
- **`id` in the box shows `nogroup` for the added GIDs** (44/992), as in the other ROCm
  boxes. Device access still works: the HIP probe above opened `/dev/kfd`.
- **The server outlives `strata launch --no-tui`.** It keeps running inside the box
  until `strata launch --stop` or `distrobox stop strata-box`. Per the repo's
  verify-process-exit rule, check `ps` in the box before calling it stopped.
- **Port 8080** collides with `llama-server`'s default.
- **Release cadence is near-daily** (0.2.0-beta → 0.2.3.1 in four days). `latest` is
  the sensible default; `CACHE_BUST` re-resolves it on every build.
- **`tools` on PATH is the installed release** (`~/.local/share/linux-tools/versions/...`),
  which doesn't know about a new app on a feature branch. Test with `./tools.sh` from the
  checkout.
